# 語彙分析時期

如同第一章討論過的，標準語言編譯器在傳統上所進行的第一階段工作就叫做 lexing（語彙分析，即「tokenizing」語法基本單元化）。

回想一下，lexing 的過程檢視一連串的原始碼字元，並指定語義給那些語法基本單元，作為某些有狀態得剖析動作的結果。

就是這個概念來理解何謂「語彙作用域」，以及這個名稱的由來。

語彙作用域（lexical scope）就是在語彙分析時期（lex-time）所決定的作用域。

換句話說，語彙作用域的決定，取決於你在「寫作時期」於何處編寫變數以及該變數所處的區塊的作用域決定的。

考慮以下程式碼：
```js
funcion foo(a){
    var b = a * 2;

    function bar(c){
        console.log(a, b, c);
    }

    bar(b * 3);
}
foo(2);// 4 4 12
```
這個程式碼範例中，有三個巢狀作用域，把這些作用域想像成存在於彼此內部的泡泡（Bubbles）或許會有些幫助，如下圖：

<img src={img_1} alt="Lexical Scope"  />

- Bubble 1 包含了全域作用域，而其中只有一個識別字：foo。
- Bubble 2 包含了 foo 函式的作用域，並且有三個識別字：a、bar 和 b。
- Bubble 3 包含了 bar 函式的作用域，並且只有一個識別字：c。

作用域泡泡（scope bubbles）的定義取決於那些作用域區塊（blocks of scope ）是在何處編寫的。
