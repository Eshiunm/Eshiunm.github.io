# 何謂作用域？

幾乎所有的程式語言（Programming Languages），都有一個最根本的能力，也就是在**變數（Variables）**中儲存**值（Values）**，
並在未來取回或修改那些值的能力。

而這種能力，讓程式擁有了「**狀態**」。

不過也由於這種能力，產生了這章節要探討的問題：「**那些變數存在何處？（Where do those variables live？）**」。

這個問題意味著我們需要定義一組良好的規範，
讓那些變數儲存在某些位置，以便於隨時可以找回那些變數，而這組規範就稱為「**作用域（Scope）**」。

--- 
因此作用域事實上是一組定義良好的「規範」，用於管理「將變數儲存在某些位置，以便於隨時可以找回那些變數」
